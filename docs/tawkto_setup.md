# Tawk.to Live Chat Setup Guide

GraceDay Inn uses **Tawk.to** as its third-party live chat provider. Tawk.to is completely free and provides real-time chat dashboard, mobile apps, offline message forms, and triggers.

Follow these steps to activate Tawk.to on the website:

## 1. Register a Free Account
1. Visit [https://www.tawk.to](https://www.tawk.to) and click **Sign Up Free**.
2. Complete the registration form with your email and password.
3. Verify your email address by clicking the link sent to your inbox.

## 2. Create your Property and Widget
1. Log in to the Tawk.to dashboard.
2. During the setup wizard (or by navigating to **Administration** ⚙️ -> **Property Settings**):
   - Enter **Property Name**: `GraceDay Inn`
   - Enter **Site URL**: `https://gracedayinn.com` (or your staging/development URL)
3. Under **Administration** ⚙️ -> **Chat Widget**:
   - Locate the **Direct Chat Link** or **Widget Code** block.

## 3. Retrieve the Embed URL
From the code snippet generated by Tawk.to, extract only the URL source value inside the `src` attribute. 
It looks like this:
```
https://embed.tawk.to/YOUR_PROPERTY_ID/YOUR_WIDGET_ID
```
For example:
```
https://embed.tawk.to/64d7a8d9cc26a8d9b8a8b8c2/1h7a8b9c2
```

## 4. Configure your `.env` File
Add the copied URL to your `.env` file at the root of the project:

```env
# Tawk.to Live Chat Widget Configuration
TAWKTO_EMBED_URL="https://embed.tawk.to/YOUR_PROPERTY_ID/YOUR_WIDGET_ID"
```

## 5. Deployment Verification
1. Restart the Django application.
2. Visit the public homepage. The Tawk.to chat widget should load automatically in the bottom-right corner.
3. Log into the Tawk.to desktop panel or download the **Tawk.to Mobile App** (iOS / Android) to receive push alerts and answer guest chats in real-time.

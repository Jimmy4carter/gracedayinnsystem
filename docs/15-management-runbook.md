# Management Runbook

## Operational alert control

1. Review **Active operational alerts** at the beginning of each shift and after notification.
2. Open the linked source record and acknowledge the alert when an owner begins investigation.
3. Correct the source condition; do not change a room status merely to hide a discrepancy.
4. Resolve manually only with concise evidence. The evaluator will also resolve alerts automatically when the condition clears.
5. A resolved condition that recurs is reopened and routed again. Repeated occurrences indicate a process or configuration problem and should be raised as a management query.
6. Administrators may tune thresholds, severity and recipient roles in Alert Rules. Keep rule types enumerated and test changes in staging before production.

## Daily control cycle

1. Review occupancy, ADR, RevPAR, revenue, receivables, pace and source mix.
2. Review room discrepancies, overdue work/inquiries, cashier variance and communication failures.
3. Raise a management query from the source record for anything requiring investigation.
4. Run night audit only after blockers clear; generate the expiring manager pack.

## Financial control

- Folio balance is immutable debits minus credits.
- Corrections require reason and manager/admin authorization.
- Review variance approvals and material corrections daily; request evidence through a query.

Weekly: review pace/cancellations, receivables, rate/promotion performance, service revenue, SLAs, feedback and recurring incidents. Sign off metric reconciliation, urgent-query ownership, failed-job disposition and configuration rollback decisions.
